# Ride Together: Medellín → México en bici

Planeación del viaje en bicicleta de Medellín al centro-norte de México (más allá de Ciudad de México).

- **Guía principal:** [reports/Viaje en bici Medellín a México.md](reports/Viaje%20en%20bici%20Medell%C3%ADn%20a%20M%C3%A9xico.md). Cubre el cruce a Panamá, las visas para colombianos, las vacunas, la documentación, la seguridad, el clima, la plata, los drones, las redes sociales y una lista de chequeo con fechas.
- **Notas de investigación:** [research_notes/Viaje en bici Medellín a México/](research_notes/Viaje%20en%20bici%20Medell%C3%ADn%20a%20M%C3%A9xico/), con las fuentes detalladas de cada tema.

La investigación es de octubre de 2026. Antes de salir y antes de cada frontera, confirmen cada requisito en la página oficial que aparece en la guía.
